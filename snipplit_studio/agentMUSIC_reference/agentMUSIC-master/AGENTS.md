# agentMUSIC

## Purpose
agentMUSIC is a **modular monolith** that turns music tracks into short-form video content (TikTok/Reels style). One Python process runs a Telegram bot, a FastAPI HTTP API, a background generation worker, and file-backed repositories; a React + Vite dashboard provides a web UI. The end-to-end flow is: import/upload a track → transcribe audio → extract chorus variants → render a video for a chosen scenario → persist metadata → expose status and downloads via the API/dashboard.

## For AI Agents

### Working In This Directory
- The bot is the single entry point: `python bot.py` launches both the Telegram bot and the FastAPI server (background thread). There is no separate API launch command in normal operation.
- Secrets come from environment variables only (loaded via `python-dotenv`). Never hardcode tokens/keys or commit `.env`.
- Non-secret tunables belong in `config.yaml`; secret/deploy config belongs in env vars (`modules/config.py`).
- API request shapes are validated by Pydantic models in `modules/validation.py` — add a model there before adding an endpoint.
- The known next refactor (per `README.md`): split `api_server.py` into domain routers (`jobs`, `tracks`, `choruses`, `videos`, `generation`, `dashboard`).

### Testing Requirements
- Backend: `pytest`, plus a compile check: `python3 -m py_compile api_server.py bot.py modules/config.py`.
- Frontend: `cd web && npm ci && npm run build && npm audit --audit-level=moderate`.
- After API changes, regenerate the checked-in schema: `python3 scripts/export_openapi.py`.

### Common Patterns
- File-backed JSON repositories under `OUTPUT_DIR/<user_id>/{_tracks,_choruses,_videos}/index.json`; all writes go through `modules/json_index.py` (atomic via temp file + `os.replace`).
- Stable error JSON shape `{ "error": CODE, "message": ... }` from `modules/errors.py`.
- In-memory job tracking via `modules/job_tracker.py`; generation runs through `modules/api_worker.py`.
