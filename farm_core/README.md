# 🐾 Plitty 3.0: Autonomous Mobile Farm & Swarm Intelligence Platform

Полноценная система управления мобильной фермой (до 30+ Android-смартфонов), автоматического прогрева аккаунтов TikTok, роевой накрутки (Swarm Intelligence) и генерации вирусного контента.

---

## 📁 Структура проекта

### ⚡ 1. Ядро автоматизации ADB (Automation Core)
* `main.py` — Главная точка входа для пакетного запуска параллельного прогрева на всех подключенных устройствах.
* `automation.py` — Сценарии органического прогрева: нежный скроллинг ленты рекомендаций, рандомизация действий, `go_to_profile_robust` (гарантированный выход в профиль).
* `boost_automation.py` — Сценарии роевого продвижения целевых видео/аккаунтов: волновые атаки, поиск по хэштегам/звукам, перепросмотр 120%+, вывод комментариев в топ.
* `nakrutka.py` / `nakrutka_night.py` — Быстрые скрипты таргетированного буста видео.
* `adb_helper.py` — Низкоуровневый асинхронный/многопоточный драйвер ADB (клики, свайпы, проверки окон, дампы UI).
* `account_personas.py` — 5 уникальных поведенческих персон (Гейминг, Мемы, Музыка, Фитнес, Лайфстайл) для разнообразия цифровых отпечатков.
* `auto_healer.py` — Диспетчер самолечения фермы: перезапуск зависших приложений, сброс шторок, восстановление ADB-соединений.
* `config.py` — Глобальные тайминги, вероятности реакций, списки аккаунтов и порты ADB (`5037`, `5038`).

### 🌐 2. Сервер и Web-интерфейс (Plitty Cloud Agent & UI)
* `cloud_agent.py` — Flask-сервер управления фермой, REST API, стриминг скриншотов, диспетчер задач.
* `web_dashboard/` — Полноценный Web Dashboard (PWA):
  * Мониторинг сетки экранов 30 телефонов в реальном времени.
  * Виджет аватара Plitty с эмоциональными реакциями и озвучкой.
  * Панель запуска задач (Прогрев / Буст / Стоп).
* `db_manager.py` — База данных SQLite (`plitty_farm.db`): история сессий, метрики девайсов, логи.
* `screen_capturer.py` — Оптимизированный сборщик скриншотов экранов с устройств.
* `tunnel_watchdog.py` — Автоматический мониторинг и перезапуск туннеля Cloudflare при разрывах сети.

### 🧠 3. Интеллект и фабрика контента (AI & Content Pipeline)
* `plitty_vision.py` — Компьютерное зрение (Computer Vision): анализ скриншотов ленты, распознавание категорий контента (котики, авто, спорт, мемы).
* `swarm_coordinator.py` — Координатор роевых атак (телефонная ОПГ): распределение ролей между телефонами для симуляции вирусного хайпа.
* `voice_engine.py` — Голосовой движок TTS для генерации реплик Plitty.
* `content_factory.py` — Пайплайн авто-генерации вертикальных Split-Screen видео (интеграция со SnipPlit).

## 🚀 Быстрый запуск

### 1. Запуск нежного прогрева всей фермы:
```bash
python main.py
```

### 2. Запуск веб-сервера и облачного туннеля:
```bash
python cloud_agent.py
.\cloudflared.exe tunnel --url http://127.0.0.1:5000
```

### 3. Таргетированный роевой буст:
```bash
python -c "from boost_automation import run_boost_session; run_boost_session('target_username')"
```
